BIOS 201 GENETICS LAUNCHPAD
====================================
A self-contained eight-week video-first genetics preparation web app.
Independent learning resource. Not affiliated with UNL.

SHARE IT AS A WEBSITE (RECOMMENDED, NO CODING):
1. Extract the ZIP. Open the BIOS201_Genetics_App folder.
2. Visit https://app.netlify.com/drop in Safari, Chrome, or another browser on a Mac.
3. Drag the entire folder (the one containing index.html) onto Netlify Drop.
4. Netlify gives you a public https://...netlify.app website link.
5. Send that link to anyone. On iPhone, open the link in Safari and select Share > Add to Home Screen; on Android, browser menu > Install app/Add to Home screen. On a Mac, bookmark it or in Safari select File > Add to Dock.

ALTERNATIVE: use GitHub Pages / Cloudflare Pages, or any static web host. No build system, database, API keys, or server code is needed.

OPEN LOCALLY ON A MAC:
Double-click index.html, or use the separately provided BIOS201_Genetics_Launchpad.html. Some browsers restrict file:// local storage and video embeds. Hosting is more reliable, especially on phones.

FEATURES:
- 8 weekly modules, 25 curated lesson resources (some are collections/animations)
- 40 auto-graded, explained multiple-choice questions; 80% mastery criterion
- 48 flashcards with spaced repetition
- 5 labs: DNA complement, DNA→RNA transcription, Punnett square, Hardy–Weinberg, recombination mapping
- Notes, video/task checkoffs, module/overall progress, light/dark display
- Progress saved privately in localStorage of each device
- Export/import JSON for moving your progress between devices
- Progressive Web App (PWA): cached interface can be used offline after first online visit. Videos remain online-only.

PLEASE NOTE:
Sharing a website link shares the curriculum, NOT your personal progress. People have separate browser storage. To move your own progress between devices, use Settings > Export progress on device A and Settings > Import backup on device B.
